# 🏕️ PackPack

**캠핑 장비를 똑똑하게 관리하는 웹 앱**

> Pack with purpose, Travel with confidence

## 📱 기능

- ✅ 캠핑 장비 리스트 관리
- ✅ 무게/가격 자동 계산
- ✅ 카테고리별 필터링
- ✅ 로컬 저장 (새로고침해도 유지)
- ✅ 모바일 친화적
- 🔜 자동 정보 검색 (개발 중)
- 🔜 이미지 자동 다운로드 (계획 중)

## 🚀 시작하기

### 1. 앱 열기
```
index.html을 브라우저에서 열기
```

### 2. 장비 추가
```
1. 제품명 입력 (예: "Salomon XT-6")
2. 카테고리 선택 (예: "신발")
3. 무게 입력 (그램)
4. 가격 입력 (달러)
5. "추가" 버튼 클릭
```

### 3. 리스트 확인
```
- 총 무게와 총 가격 자동 계산
- 카테고리별로 필터링
- 각 항목 편집/삭제 가능
```

## 📊 데이터 저장

모든 데이터는 브라우저의 로컬 저장소(localStorage)에 저장되므로:
- 새로고침 후에도 유지됨
- 다른 기기에서는 보이지 않음
- 브라우저 캐시 삭제시 초기화됨

## 🛠️ 개발 중인 기능

### Phase 2: 자동 검색
```
제품명 또는 링크 입력
     ↓
자동으로 인터넷에서 정보 수집
     ↓
무게, 가격, 이미지 자동 추가
```

### Phase 3: 완전 자동화
```
AI가 자동으로 정보 검증
여러 사이트에서 동시 검색
가장 정확한 정보 선택
```
