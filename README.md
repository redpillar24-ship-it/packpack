# 🏕️ PackPack

**LighterPack에서 영감을 받은 장비 관리 웹 앱**

> Pack with purpose, Travel with confidence

제품 링크를 붙여넣으면 서버가 해당 페이지에서 이름/이미지/가격/무게/설명을 자동으로 읽어와 폼을 채워줍니다. 사이트마다 구조가 달라 100% 정확하지는 않으므로, 신뢰도가 낮은 값은 입력창 테두리가 주황색으로 표시되고 사용자가 직접 확인/수정할 수 있습니다.

## 구조

```
public/          프론트엔드 (HTML/CSS/JS, 정적 파일)
server/
  server.js      Express 서버 (정적 파일 서빙 + API)
  extractor.js   제품 페이지에서 정보를 추출하는 핵심 로직
```

- 장비 데이터는 브라우저 localStorage에 저장됩니다 (서버는 DB를 쓰지 않음).
- 서버는 사용자가 붙여넣은 링크의 HTML을 가져와 파싱하는 역할만 합니다. 완전 무료로 동작하며 별도 API 키가 필요 없습니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

개발 중 저장할 때마다 자동 재시작하려면:

```bash
npm run dev
```

## 자동 정보 검색 동작 방식

1. 사용자가 제품 페이지 URL을 입력하고 "🔍 자동 채우기" 클릭
2. 서버(`/api/extract`)가 해당 페이지를 가져와서:
   - `JSON-LD`(schema.org Product) → 메타 태그(`og:price`, `og:title` 등) → 페이지 내 텍스트 패턴 순으로 이름/가격/무게를 탐색
   - "관련 상품", "추천 상품" 영역은 제외하고 본문 스펙 영역을 우선 탐색해 오염을 줄임
3. 신뢰도가 낮게 판단된 값(예: 비정상적으로 큰 가격, 페이지 전체 검색으로만 찾은 무게)은 `confidence: low`로 표시되어 프론트엔드에서 시각적으로 경고됨

### 알려진 한계

- 일부 사이트는 봇 접근을 차단해 403 에러가 날 수 있습니다 (이 경우 수동 입력 필요).
- 일부 해외 쇼핑몰(Shopify 기반 등)은 접속 IP 지역에 따라 통화를 자동 환산해서 내려주면서도 통화 태그를 잘못 표기하는 경우가 있어, 가격이 부정확할 수 있습니다. 비정상적으로 큰 금액은 자동으로 저신뢰도 처리됩니다.
- 제품명만으로 검색(사이트를 몰라도 자동으로 찾아주는 기능)은 아직 지원하지 않습니다. 무료로 구현하려면 검색엔진 API가 필요한데 대부분 유료/제한적이라 2단계 기능으로 남겨두었습니다.
