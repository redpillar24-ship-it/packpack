# 🏕️ PackPack - 캠핑 장비 리스트 앱

## 프로젝트 개요

**PackPack**은 캠핑 장비를 효율적으로 관리하는 웹 애플리케이션입니다.

- **영감**: Lighterpack.com (더 사용하기 쉬운 버전으로 만들기)
- **목표**: 사용자가 최소한의 입력으로 캠핑 장비를 최적화하도록 도와주기
- **모토**: "Pack with purpose, Travel with confidence"

---

## 핵심 기능

### Phase 1: 기본 UI (현재 단계) ✅
사용자가 직접 입력하는 기본 기능

- [ ] 제품명 입력 폼
- [ ] 무게(g) 입력 필드
- [ ] 가격($) 입력 필드
- [ ] 수량 입력
- [ ] 설명 입력
- [ ] 카테고리 선택 (옷, 텐트, 취사도구 등)
- [ ] 이미지 업로드
- [ ] 리스트 표시
  - 제품명, 무게, 가격, 수량
  - 총 무게 / 총 가격 자동 계산
- [ ] 편집 기능
- [ ] 삭제 기능
- [ ] localStorage로 저장 (새로고침해도 유지)
- [ ] 필터링 (카테고리별)

### Phase 2: 자동 검색 (나중) 🔜
API를 통한 반자동 정보 수집

- [ ] 제품명 또는 링크 입력
- [ ] 자동 검색 (무료 API 사용)
- [ ] 검색 결과 중 선택
- [ ] 자동 정보 채우기 (무게, 가격, 이미지)
- [ ] 사용자 검증 후 추가

### Phase 3: 완전 자동화 (향후) 🚀
AI와 스크래핑을 통한 완전 자동화

- [ ] 구글 이미지 검색 (이미지 자동 다운로드)
- [ ] 여러 사이트 자동 크롤링
- [ ] 정보 검증 (AI)
- [ ] 완전 자동 추가

## 기술 스택

### Phase 1
- **프론트엔드**: HTML, CSS, JavaScript (외부 라이브러리 없음)
- **저장소**: localStorage (브라우저 로컬 저장)
- **배포**: Vercel (무료)

### Phase 2+
- **백엔드**: Node.js (필요시)
- **API**: 무료 API 활용
  - Serper API (검색, 월 100회 무료)
  - DuckDuckGo API (무료)
  - 또는 Bing Search API (무료 티어)
- **데이터베이스**: Firebase 무료 티어

```javascript
  price: 139.99,                  // USD ($)
  quantity: 1,                    // 개수
  description: "Outdoor hiking boot", // 설명
  image: "url_or_base64",         // 이미지
  link: "https://...",            // 공식 링크 (Phase 2+)
  createdAt: "2026-08-12"         // 생성 날짜
}
```

## 개발 가이드

### 파일 구조
```
packpack/
├─ .claude/
│  ├─ settings.json     (프로젝트 설정)
│  └─ CLAUDE.md         (이 파일)
├─ index.html           (HTML 구조)
├─ style.css            (CSS 스타일)
├─ script.js            (JavaScript 로직)
├─ README.md            (사용자 설명서)
└─ data.json            (샘플 데이터, Phase 2+)
```

### 코딩 규칙
- 함수명: camelCase (getGearList, addGear)
- 변수명: camelCase
- 클래스명: PascalCase (필요시)
- 주석: 한국어 (이해하기 쉽게)

### 저장 방식
- localStorage 키: `packpack_gears` (JSON 배열)
- 로컬 백업: 주간 export 기능
